# 買い時スクリーニング

日本株の全銘柄から条件に合う銘柄を毎日自動で洗い出し、1枚のページに点数順で表示する仕組みです。
あわせて、朝の相場予想で使う個別銘柄の株価データ（四本値・出来高）もここで取得しています。

データはすべて JPX 公式の **J-Quants API（v2）** から取っています。
日中の途中経過の株価だけは、無料の遅延株価（yfinance）で補っています。

公開ページ：https://kaneda30000000.github.io/stock-screener/

## 自動で動くもの

GitHub Actions が下の時刻に自動で動きます。手で何かする必要はありません。

### スクリーニング（`.github/workflows/screen.yml`）

| 時刻（日本時間） | やること |
|---|---|
| 深夜 2:00（月〜金） | 全銘柄を一から調べ直す（`full`）。決算・株価・PER などを J-Quants から取り直す |
| 11:35（平日） | 前場引け後。候補に近い銘柄（最大600）の株価を取り直して点数を再計算（`intraday`） |
| 16:00（平日） | 大引け後。同じく株価を取り直して点数を再計算（`intraday`） |

- 結果は `docs/index.html`（ページ）と `docs/latest.json`（データ）に書き出され、GitHub Pages で公開されます。
- 実行の記録は `data/summary.json` に残ります。
- 取り込んだ株価と決算は GitHub Actions のキャッシュに貯めておき、次の回は差分だけを取りに行きます。
- 休場日の `intraday` は何もせずに終わります。

### 予想用の四本値（`.github/workflows/jq-forecast.yml`）

| 時刻（日本時間） | やること |
|---|---|
| 18:30（平日） | 当日の四本値・出来高を取得 |
| 5:20（平日） | 朝の相場予想（6:01）の前に念のため取り直す |

- 対象は次の5銘柄で、直近約100営業日分を取ります。
  - 予想の対象：8306 三菱UFJ FG、7203 トヨタ自動車、9984 ソフトバンクG
  - 指数の出来高の代わり：1321（日経225連動ETF）、1306（TOPIX連動ETF）
- 結果は `data/jq_forecast.json` に保存されます。
- Claude の定期タスク「朝の相場予想」が、毎朝このファイルを読んで前日終値・値動きの幅・出来高に使います。

## スクリーニングの条件

### 必須条件（4つすべてを満たす銘柄だけを表示）

1. **業績**：直近の本決算が4期連続で増収かつ増益
2. **PER**：0倍より大きく19倍以下（会社予想の1株利益を使用。赤字は除外）
3. **流動性**：直近20営業日の平均売買代金が3,000万円以上
4. **配当**：過去5年で減配していない（ずっと無配でも通る）

対象はプライム・スタンダード・グロースの全銘柄です（REIT・ETF などは除外）。

### ポイント（今の設定では270点満点）

必須条件を通った銘柄に、下の13項目で点数を付けて合計点の高い順に並べます。

| 項目 | 最高点 | 最高点の条件 |
|---|---|---|
| PER | 30 | 10倍以下 |
| 四半期の増収率（前年同期比） | 30 | 20%以上 |
| 四半期の増益率（前年同期比） | 30 | 20%以上 |
| 売上の進捗率（会社予想に対して） | 30 | 120%以上 |
| 営業利益の進捗率（会社予想に対して） | 30 | 120%以上 |
| 3か月高値からの下落率 | 15 | 30%以上下落 |
| レンジ（横ばい）に入ってからの日数 | 15 | 60営業日以上 |
| 営業利益率 | 15 | 25%以上 |
| 営業利益の年平均成長率 | 15 | 年20%以上 |
| 配当利回り | 15 | 4%以上 |
| 配当性向 | 10 | 20〜40% |
| PBR | 10 | 1倍割れ |
| 自己資本比率 | 10 | 60%以上 |

- 「3か月高値」は直近60営業日の高値です。
- 「レンジ」は、直近20営業日の値幅が平均株価の12%以内に収まっている状態です。
- 条件を通った銘柄のうち、前日比−10%以下、または直近3営業日で−15%以下になったものは、一覧の上に**急落銘柄**として別枠で表示します。

### 条件や配点を変えたいとき

**`config.yml` の数字を書き換えるだけ**で変えられます。プログラムを触る必要はありません。
書き換えたあと、Actions タブから「スクリーニング」を `full` で手動実行すると、すぐにページに反映されます。

## 設置の手順（新しく作り直すときだけ）

### 1. J-Quants の APIキーを登録する

1. J-Quants の管理画面の **[API Keys]** で APIキーを発行します。
2. このリポジトリの **Settings → Secrets and variables → Actions → New repository secret** を開きます。
3. Name に `JQ_API_KEY`、Secret に発行したキーを入れて保存します。

- 2つのワークフローとも、このキーを使います。
- 以前の設定の `JQ_PASSWORD` にキーが入っている場合も、そのまま使えます。
- メールアドレスとパスワードでのログインは使いません（`JQ_MAIL` は不要です）。
- 決算は5年分（ライトプランの上限）を使います。無料プランではデータが約12週間遅れるため、この仕組みは使えません。

### 2. ページの公開設定

**Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にします。

### 3. 最初の1回を手で動かす

1. **Actions** タブを開き、「スクリーニング」→ **Run workflow** を押します。mode は `full` のまま実行します。
   - 初回は過去5年分の決算をまとめて取り込むため **20〜30分** かかります。2回目以降は数分で終わります。
2. 続けて「予想用の四本値（J-Quants）」→ **Run workflow** も実行します（10秒ほどで終わります）。
   - ログの「最新日」が当日か前の営業日になっていれば正常です。

## うまく動かないとき

Actions タブで赤い × が付いた実行を開くと、日本語のエラーが出ています。よくあるもの：

| 表示 | 原因と直し方 |
|---|---|
| `APIキーが設定されていません` | Secrets に `JQ_API_KEY` がありません。設置の手順1を行う |
| `APIキーではなくメールアドレスが入っているようです` | Secret にメールアドレスを入れています。管理画面で発行したキーに入れ替える |
| `APIキーが拒否されました（403）` | キーの打ち間違いか、前後に余分な空白があります。貼り直す |
| `〜へのアクセスが拒否されました（403）` | 契約プランでそのデータが使えません。プランを確認する |
| `本決算（通期）のデータが1件も取れませんでした` | 契約プランを確認する |
| `決算データの取得が10回連続で失敗したので中断しました` | J-Quants 側の一時的な不調です。もう一度実行すると続きから再開します |
| `日中株価が取得できず前日終値のまま`（ページの表示） | 無料の遅延株価が一時的に取れませんでした。次の回で直ります |
| `can't open file '…/scripts/jq_forecast.py'` | `jq_forecast.py` が `scripts` フォルダの外に置かれています。`scripts` の中へ移す |
| 予想用の四本値で「最新日が〜で古い」 | 配信が遅れています。契約プランを確認する |

## ファイルの中身

```
config.yml                          条件と配点の設定（ここだけ触れば調整できる）
requirements.txt                    必要なライブラリ
.github/workflows/screen.yml        スクリーニングの自動実行スケジュール
.github/workflows/jq-forecast.yml   予想用の四本値の自動実行スケジュール
scripts/run.py                      スクリーニング本体（J-Quants との通信・計算・ページ作成をこの1ファイルで行う）
scripts/jq_forecast.py              予想用の四本値・出来高の取得
docs/index.html                     公開されるページ（自動で上書きされる）
docs/latest.json                    ページに載せた銘柄のデータ（自動で上書きされる）
data/summary.json                   直近の実行の記録（自動で上書きされる）
data/jq_forecast.json               予想用の四本値・出来高（自動で上書きされる）
```

`scripts/jq.py`、`fetch.py`、`score.py`、`quote.py`、`render.py`、`selftest.py` は、
1ファイルにまとめる前の古いファイルです。今は使っていないので、消してもかまいません。
