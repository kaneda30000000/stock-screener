# 買い時スクリーニング

日本株の全銘柄から、条件に合う銘柄を毎日自動で洗い出して1枚のページに表示する仕組みです。

## 何をしているか

| 時刻（日本時間） | やること |
|---|---|
| 深夜 2:00 | 全銘柄を一から調べ直す。決算の確報まで反映済み |
| 11:35 | 前場引け直後。候補銘柄の株価を取り直して点数を再計算 |
| 16:00 | 大引け後。同じく株価を取り直して点数を再計算 |

結果は `docs/index.html` に書き出され、GitHub Pages で公開されます。

## 必須条件

1. 直近の本決算が**連続で増収かつ増益**（既定は4期連続）
2. **PERが15倍以下**（会社予想の1株利益を使用）
3. 直近60営業日の高値から**10%以上下落**し、直近20営業日が**横ばい（レンジ）**になっている
4. 平均売買代金が3,000万円以上（板が薄すぎる銘柄を外すため）

## ポイント（95点満点）

配当利回り・配当性向・PER・PBR・下落率・レンジ日数・自己資本比率・営業利益率・営業利益の成長率の
9項目に点数を振り、合計点の高い順に並べます。

条件も配点も **`config.yml` の数字を書き換えるだけ**で変えられます。

## 設置の手順

### 1. GitHubにパスワードを預ける

リポジトリの **Settings → Secrets and variables → Actions → New repository secret** で2つ登録します。

| Name | Secret |
|---|---|
| `JQ_MAIL` | J-Quantsに登録したメールアドレス |
| `JQ_PASSWORD` | J-Quantsのパスワード |

ここに入れた値は暗号化され、ページにも実行ログにも出ません。

### 2. ページの公開設定

**Settings → Pages → Build and deployment → Source** を **「GitHub Actions」** にします。

### 3. 最初の1回を手で動かす

**Actions** タブ →「スクリーニング」→ **Run workflow** → mode は `full` のまま実行。

初回は過去5年分の決算をまとめて取りに行くため **20〜30分** かかります。
2回目以降は数分で終わります。

終わると公開URLが使えるようになります。

```
https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/
```

このURLをスマホとPCのブラウザにブックマークしておけば、いつでも最新版が見られます。

## うまく動かないとき

Actions タブで赤い×が付いた実行を開くと、日本語のエラーが出ています。よくあるもの:

- `ログインに失敗しました` … `JQ_MAIL` / `JQ_PASSWORD` の打ち間違い
- `本決算（通期）のデータが1件も取れませんでした` … J-Quantsのプランが無料のまま
- `日中株価が取得できず前日終値のまま` … 無料の株価取得が一時的に失敗。次の回で直ります

## ファイルの中身

```
config.yml                     条件と配点の設定（ここだけ触れば調整できる）
requirements.txt               必要なライブラリ
.github/workflows/screen.yml   自動実行のスケジュール
scripts/jq.py                  J-Quants APIとの通信
scripts/fetch.py               株価・決算を集めて貯める
scripts/score.py               条件の判定とポイント計算
scripts/quote.py               日中の最新株価の取得
scripts/render.py              HTMLページの生成
scripts/run.py                 実行の入り口
scripts/selftest.py            ダミーデータでの動作確認（ネット不要）
docs/index.html                公開されるページ（自動で上書きされる）
```
